# اسلام بلوچی — Islam Balochi

## ⚠️ موادانی شنگ کنگ ءِ حق

### بلوچی
«اسلام بلوچی» ءِ ھچ موادے — نبشتہ، رجانک، پَرّیچ، توار بند، عکس ءُ ڈیزائن — کس پہ ھچ رنگیں سوبے ءَ ھچ جاگہ کارمرز کت نہ کنت ابید ءِ اجازت ءَ۔
چہ اے ایپ ءَ زرتگیں ھچ موادے ءِ زورگ ءُ دگہ ایپے ءَ مان کنگ ءِ حق کس ءَ نیست اِنت۔
اگاں یکے نبشتہ یا کتابے ءِ واستا موادے کاپی کنت گڑا الم سرجمیں حوالہ ءَ بدنت۔

### اردو
«اسلام بلوچی» کا کوئی بھی مواد — تحریر، ترجمہ، تفسیر، آڈیوز، تصاویر اور ڈیزائن — کوئی بھی شخص کسی بھی مقصد کے لیے کسی بھی جگہ بغیر اجازت استعمال نہیں کر سکتا۔
اس ایپ کا کوئی بھی مواد لے کر کسی دوسری ایپ میں شامل کرنے کی کسی کو اجازت نہیں۔
اگر کوئی تحریر یا کتاب کے لیے کچھ نقل کرے تو مکمل حوالہ دینا لازم ہے۔
